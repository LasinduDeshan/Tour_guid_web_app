# Tour Guid

A premium travel and tour operator web application built with Next.js, inspired by [Tour Guid](https://www.tourguid.com/).

## Features
- **Modern UI**: Inspired by high-end travel websites with glassmorphism and smooth animations.
- **Role-Based Access Control**: Separate views and permissions for Admin and General Users.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile.
- **Tour Management**: Admin interface for managing tour packages.

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)
